# Проверки реализации

Дата: 27 октября 2026 года.

## Автоматические тесты

Выполнено из корня портфолио с предоставленным средой Node.js:

```sh
node --test morgayka/tests/*.test.cjs
```

Результат: 25 тестов, 25 пройдено, 0 ошибок. Команда `node --test` из папки проекта также выполнена: 25 тестов пройдено. Использован Node.js v24.22.1. Проверка синтаксиса `src/app.js` прошла. Локальные ссылки на файлы проверены; базовый поиск шаблонов секретов совпадений не обнаружил. Это не полный аудит безопасности.

14 тестов временной модели и контроллера, 11 тестов интеграции с DOM-адаптером. В адаптере проверены Esc, pointerdown, blur, visibilitychange, fullscreenchange, запрет live-запуска в demo-only, отказ fullscreen, неверный ввод, связь ползунка с полем и завершение с возвратом управления.

Тесты адаптера не подтверждают особенности доставки событий конкретным браузером или ОС.

## Проверка в браузере

Использован встроенный браузер среды разработки. Проект отдавался временным сервером Python на `127.0.0.1:8765`; разрешение на такой способ проверки получено у владельца. Для обычного запуска сервер не нужен.

Подтверждено взаимодействием с интерфейсом:

- Первоначальный экран без стимуляции.
- При `?demo=1` кнопка настоящей стимуляции отключена.
- Ввод 1,2 Гц отклонён с сообщением, fullscreen не запущен.
- Демонстрация входит в полный экран без элементов управления поверх поля.
- Демонстрация на 5 секунд автоматически завершается и возвращает настройки.
- Щелчок по полю завершает демонстрацию с соответствующей причиной.
- Esc завершает демонстрацию с соответствующей причиной.
- В отчёте есть интервалы rAF; они меняются от нагрузки и не подменяются выбранной частотой.
- На ширине 390 px поля перестраиваются в колонку; ширина документа 390 px, горизонтального переполнения не обнаружено.
- В проверенной сессии сообщений warn/error в консоли не зарегистрировано.
- Скриншоты получены с реальной страницы: основной экран, мобильный экран, результат демонстрации.

В режиме проверки вкладки среды разработки не воспроизвели обычное скрытие вкладки при создании второй вкладки. Поэтому потеря фокуса и скрытие проверены автоматическими тестами обработчиков, но не считаются подтверждёнными ручной проверкой на целевых ОС.

## Ещё не проверено

- Открытие по `file://` в Firefox на macOS и Edge/Chrome на Windows. Встроенный инструмент запрещает `file://`, поэтому использован согласованный локальный HTTP-сервер.
- Настоящая смена фокуса приложения, переключение вкладок и отдельная команда выхода из fullscreen на целевых ОС.
- Реальная красно-чёрная стимуляция на физическом экране: во время проверок использовалась демонстрация без вспышек.
- Физическая точность частоты, яркость, цветопередача, разные мониторы и частоты обновления.
- Клиническая пригодность и медицинская сертификация.

До ручной проверки целевых браузеров реализация остаётся кандидатом MVP, а не полностью подтверждённым выпуском.

## Ручная приёмка без вспышек

В Firefox на macOS и отдельно в Edge/Chrome на Windows:

1. Открыть `index.html` локально. Убедиться, что мигания нет, шрифт и оформление загрузились без интернета.
2. Выбрать 5 секунд, нажать «Демонстрация без вспышек». Дождаться завершения; проверить возврат и сохранение выбранных параметров.
3. Выбрать 120 секунд. Повторить демонстрацию и остановить щелчком. Повторить с Esc.
4. Повторить демонстрацию, переключиться в другое приложение. Вернуться: сессия завершена, сама не продолжается.
5. Повторить со сменой вкладки и с командой браузера для выхода из полного экрана. Проверить завершение в каждом случае.
6. Ввести пустое поле, 1,2 Гц, 0 секунд и 125 секунд. Каждый вариант должен блокировать запуск с понятным сообщением.
7. Проверить ползунки, клавиатуру Tab и изменение масштаба до 200%.
8. Добавить `?demo=1` к адресу. Убедиться, что настоящую стимуляцию нельзя запустить кнопкой.
9. Записать версии браузера и ОС, способ запуска, результат и обнаруженные ошибки.

Отказ fullscreen проверен автоматическим адаптером; при ручной проверке, если браузер позволяет запретить полный экран штатной настройкой, ожидается сообщение об ошибке и отсутствие активного поля.
